A faster drop-in for makefun-site 1.0.0: `solve.js` returns, for every case, byte-for-byte the build output makefun-site 1.0.0 produces, with the hot paths cached.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json`, answers each with `run`, and writes `/output/answers.json`.
